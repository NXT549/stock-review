Stock Review

Pick a list of stocks: the ASX 200, the S&P 500, all of Japan, or your own tickers. Click Run. Stock Review pulls the latest numbers from Yahoo Finance and writes them into one tidy report that you can drop into any AI chat.

Free and Windows-only. Everything runs on your own computer. There's no AI inside the app.

What it does

One run gives you one file to hand to an AI

1. Pick
  • Regions: S&P 500/400/600/1500, ASX 200, every ASX listing, Japan, UK, Germany, Hong Kong, Canada, India, plus small-cap sleeves and global combos
  • Sectors: energy, mining, telecom, tech, financials, healthcare and more, optionally limited to one region
  • Your own list: type tickers (AAPL BHP.AX 7203.T) or load a .txt or .csv file
2. Fetch
  • For each company: size (in USD), valuation (P/E, PEG, P/B, P/S), quality (ROE, margin, growth, debt), dividends
  • Momentum: 1, 3, 6 and 12-month returns, distance from the 50- and 200-day averages, and from the 52-week high and low
  • Analyst rating, price target and upside
3. Read

You get one date-stamped report. The default Markdown version is a compact table with a column legend and built-in instructions for the AI that will read it. You can also export CSV for Excel or JSON for scripts.

Install

Install in about a minute

  1. Download Stock-Review-Setup.exe.
  2. Open it. If you see a blue "Windows protected your PC" box, click More info, then Run anyway. This only means the app is new to Windows. You'll only see it once.
  3. Click Next → Install → Finish. You don't need an admin password or Python.
  4. Open Stock Review from your desktop, pick something from Quick picks, click ▶ Run review, then click Open report.

💡 Tip of the Day: Yahoo limits how fast you can pull data on big runs. If some tickers say FAIL, wait a few minutes and run the same thing again. It picks up where it left off and fills in the gaps.

Reports are saved to Documents\Stock Review\reports.

The honesty rule

It never makes up a number

If…Stock Review…
Yahoo doesn't have a valueleaves the cell blank (or shows n/a in rich mode). It never fills in 0 or a guess.
A ticker can't be fetchedlists it in a "could not fetch" section instead of quietly dropping it
Yahoo rate-limits youretries politely with growing pauses, shows each retry, and saves its progress so a rerun resumes
You click Cancelstill writes everything fetched so far as a clearly marked partial report
A ticker doesn't really belong in the sector you pickedremoves it and lists it, along with the industry that ruled it out

The app only connects to Yahoo Finance. There are no accounts and no telemetry.

Little luxuries

Built like a proper 90s program

  • 13 ASCII-art channels play while it works (rocket, whale, bank vault, harbour…). Double-click the DOS title bar to switch.
  • Quick picks, tooltips, Recent reports, Tip of the Day, a Crystal Ball (Ctrl+8) and a lifetime odometer
  • A Terminal edition that runs the same engine with command-line flags and the animations in your console
  • For developers, the repo also includes a deterministic 0–100 scoring pipeline with a backtest harness. See the README.
⚠ Important

Not financial advice. Stock Review is an automated research screen that gathers numbers into a tidy file. Yahoo Finance data can be wrong, delayed or missing, so check it before you act on anything. Decisions are yours (and ideally a licensed adviser's).
