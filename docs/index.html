What it does

One run gives you one file to hand to an AI.

There is no account, no telemetry and no AI inside the app. It gathers the numbers; you choose who reads them.

01

Pick

  • Regions: S&P 500/400/600/1500, ASX 200, every ASX listing, Japan, UK, Germany, Hong Kong, Canada, India, plus small-cap sleeves and global combos
  • Sectors: energy, mining, telecom, tech, financials, healthcare and more, optionally limited to one region
  • Your own list: type tickers (AAPL BHP.AX 7203.T) or load a .txt or .csv file
02

Fetch

  • For each company: size (in USD), valuation (P/E, PEG, P/B, P/S), quality (ROE, margin, growth, debt), dividends
  • Momentum: 1, 3, 6 and 12-month returns, distance from the 50- and 200-day averages, and from the 52-week high and low
  • Analyst rating, price target and upside
03

Read

  • One date-stamped report. The default Markdown version is a compact table with a column legend and built-in instructions for the AI that will read it
  • Copy for AI puts the whole report on your clipboard
  • Or export CSV for Excel, or JSON for scripts

The honesty rule

It never makes up a number.

Yahoo doesn't have a valueThe cell stays blank (or shows n/a in rich mode). It is never filled with 0 or a guess.
A ticker can't be fetchedIt is named in the window and listed in a "could not fetch" section of the report instead of being quietly dropped.
Yahoo rate-limits youThe app retries politely with growing pauses, shows each retry, and saves its progress so a rerun resumes.
You press Cancel or Finish nowEverything fetched so far is still written, as a clearly marked partial report.
A ticker doesn't belong in the sector you pickedIt is removed and listed, along with the industry that ruled it out.

The app connects to Yahoo Finance for the numbers, and to Wikipedia and the ASX for index membership lists. Nothing else.

Install

Up and running in about a minute.

  1. Download Stock-Review-Setup.exe.
  2. Open it. If you see a blue "Windows protected your PC" box, click More info, then Run anyway. This only means the app is new to Windows. You'll only see it once.
  3. Click Next → Install → Finish. You don't need an admin password or Python.
  4. Open Stock Review from your desktop, pick a list in the sidebar, press Run review, then Copy for AI.
Download Stock-Review-Setup.exe

Reports are saved to Documents\Stock Review\reports.

Big runs get rate-limited. If some tickers say Failed, wait a few minutes and run the same thing again. It picks up where it left off and fills in the gaps.
